# 安装后验证清单

装好后逐项检查。建议每项都实际进游戏看一遍，而不是只看文件是否存在。

## 1. 基础

- [ ] 启动后，设置里的语言显示为「简体中文」
- [ ] `logs\ags.log` 里有 `Translation loaded: 简体中文.tra`
- [ ] 主菜单、存档/读档界面是中文
- [ ] 没有方块字、没有文字被裁掉

失败时看 `README.md` 的常见问题，或运行：

```powershell
powershell -ExecutionPolicy Bypass -File verify_setup.ps1 -GameDir "<游戏目录>"
```

## 2. 对话与界面

- [ ] 开场旁白/对话是中文
- [ ] 鼠标指向物体，上方动作文字正常（如「闹钟 查看」）
- [ ] 轮盘左右两个按钮都能点，并有文字
- [ ] 物品栏里的物品名是中文
- [ ] 笔记本：条目名与电话号码都显示，没有重叠
- [ ] 电话簿：姓名与号码对齐
- [ ] 电脑界面（登录、终端提示）不叠字、不裁字

## 3. 关键剧情点

- [ ] 回宿舍、舍友留便条：**不黑屏、不卡死**
- [ ] 40 号房间的过场能正常进入并继续
- [ ] 警察局给神父听录音：听完能继续，不卡在 `Wait`
- [ ] 第二刀（怪物形态）能触发
- [ ] 结局字幕/题词能正常显示

## 4. 故意保留英文的地方（不是 bug）

以下内容必须保持英文，否则游戏无法判定：

- [ ] VoiceForge 语音拼装谜题：`HELLO ERICA / IT'S YOUR FATHER / CALL KATHY RAIN ... / BYE`
- [ ] 冰箱贴拼字：`HOPES IN JAR` / `AN INKIER HEART` / `RULE ME NEMESIS`
- [ ] 部分脚本用 `IndexOf` 等待的单词（如录音字幕里的 `sons`）

## 5. 已知问题（不阻塞通关）

- 笔记名短于 8 个字符时，该行可能没有电话号码（引擎已做越界保护，不会崩溃）
- 图片里的文字（海报、便签、书页）无法翻译，属于美术资源
- 设置菜单里的部分文字来自原版图片资源，保持原样

## 6. 回滚

- [ ] 把 `KathyRain.exe.orig` 改回 `KathyRain.exe`
- [ ] 删除 `简体中文.tra`、`zh.ttf`
- [ ] `acsetup.cfg` 中 `translation=` 清空
